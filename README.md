# 🏨 RD Hotel Management System

A modern and responsive Hotel Management Web Application designed to simplify hotel booking, room management, customer interaction, and hospitality services through an interactive and scalable platform.

---

## 🚀 Project Overview

RD Hotel Management System is a full-stack web application developed using ASP.NET Core, React, TypeScript, HTML, CSS, and SCSS.  
The project focuses on delivering a smooth hotel booking experience with modern UI/UX design and efficient backend services.

This application allows users to explore hotel rooms, check room details, search available rooms, and interact with hotel services through a responsive interface.

---

# ✨ Key Features

✅ Responsive and Modern User Interface

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/vijayaragavid/RD-Hotel-webite.git
```

## 2️⃣ Navigate to the Project Directory

```bash
cd RD-Hotel-webite
```

## 3️⃣ Install Frontend Dependencies

```bash
npm install
```

## 4️⃣ Run the Application

```bash
dotnet run
```
